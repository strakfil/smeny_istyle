# Směny iSTYLE

A simple web application for generating and managing employee shift schedules for iSTYLE stores.

🌐 **Live application:** https://smenyistyle.streamlit.app/

## Features

- 📅 Interactive shift planner
- 👥 Employee management
- ⚡ Fast and intuitive interface
- 🌐 Accessible from any device
- ☁️ Hosted on Streamlit Community Cloud

## Tech Stack

- Python
- Streamlit

## Running locally

```bash
git clone https://github.com/strakfil/smeny_istyle.git
cd smeny_istyle
pip install -r requirements.txt
streamlit run app.py
```
